About the data

データについて

YAMLを正本とし、Web表示用JSONと確認・参照・印刷用CSVを同じデータから生成しています。 CSVとJSONは直接編集せず、YAMLのバージョン更新時に全件再生成します。

旧字体・異体字は可能な限り原資料の表記を保持しています。 OCRと画像目視でも判読に不確実性が残る箇所は「要確認」として明示しています。

原資料は那珂市「那珂市刊行物」をご覧ください。
